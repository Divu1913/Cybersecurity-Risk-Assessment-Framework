# Cybersecurity Risk Assessment Framework for SMEs

## Project Overview
This project focuses on developing a Cybersecurity Risk Assessment Framework for Small and Medium Enterprises (SMEs).

The project analyzes common cybersecurity threats affecting SMEs and proposes mitigation strategies to improve organizational security posture.

## Project Objectives
- Identify cybersecurity risks in SMEs
- Analyze phishing, ransomware, insider threats, and weak security practices
- Develop a cybersecurity risk assessment model
- Evaluate risks using likelihood and impact analysis
- Suggest mitigation strategies and security best practices
- Study cybersecurity awareness in small businesses

## Technologies and Concepts Used
- NIST Cybersecurity Framework
- Risk Assessment Matrix
- Cybersecurity Threat Analysis
- Risk Severity Evaluation
- Firewall and Antivirus Concepts
- Multi-Factor Authentication (MFA)
- Access Control Policies
